# ATM (Java)

## Description

This is a simple ATM program made using Java. It allows the user to check the balance, deposit money and withdraw money after entering the correct PIN.

## Features

- PIN Login
- Check Balance
- Deposit Money
- Withdraw Money
- Exit

## Technologies Used

- Java
- Scanner

## How to Run

Compile:

javac ATM.java

Run:

java ATM
